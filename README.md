# ROOF · Поиск дублей объектов и фотографий (MVP-1)

Антифрод-система для портфолио подрядчиков ROOF: находит дубли объектов и
переиспользованные фотографии, считает **Duplicate Risk Score** и выводит
подозрительные случаи в очередь модерации. Реализация по нормативному стеку
TN Life (Go-монолит + Vue 3 + PostgreSQL), **поиск без ИИ**.

## Как ищем дубли (без ИИ)

| Тип | Метод |
|---|---|
| Точный дубль файла | SHA-256 |
| Почти-дубль / правки | перцептивные хеши pHash + dHash + aHash, Hamming-расстояние |
| Дубль данных объекта | сравнение карточек: название/адрес (Левенштейн), подрядчик, заказчик, год, GPS (гаверсинус), один `roof_id` |
| Один объект разными подрядчиками | контекст: число совпавших по хешам фото + совпадение карточек |

Risk Score 0–100 считается по факторам ТЗ §6.2, каждое решение **объяснимо**
(в карточке видно, какие признаки сработали). Пороги настраиваются через env
без релиза кода.

## Запуск локально (Docker)

```bash
cd infra
docker compose up --build
```

Поднимутся `postgres`, `backend`, `frontend`, и одноразовый `seed`, который
загрузит тестовые данные из `downloaded_photos/` и `таблица дублей фото и данных_V2.xlsx`
(метаданные объектов сопоставляются с фото по `roof_id`, поэтому устойчивы к сдвигу строк между версиями таблицы).

- UI модерации: **http://localhost:8080** → раздел «Дубли»
- API напрямую: **http://localhost:8081/api/v1/ext/health**

Первый запуск собирает образы и обрабатывает ~150 фото — это занимает 1–3 минуты.
Прогресс обработки виден в строке статистики UI (`в обработке: N`).

## Что увидите (встроенные демо-кейсы из данных)

- **Высокий риск, cross-contractor**: 8 байт-в-байт идентичных фото у двух разных
  подрядчиков/объектов (`row10` ↔ `row44`) → точный дубль файла, score 100+.
- **Дубль карточки объекта**: объект ROOF `84022 ТЦ Опалиха` заведён дважды
  (`row34` ↔ `row35`) + 3 общих фото → высокий object_context-риск.

Клик по строке открывает карточку сравнения: оба фото, обе карточки объектов,
расшифровка факторов риска и действия модератора (подтвердить дубль / не дубль /
похоже, но не дубль / фото производителя / чужое портфолио).

## Структура

- `backend/` — Go-монолит: ingest-pipeline, хеши, скоринг, модерация, `/metrics`, OpenAPI.
- `frontend/` — Vue 3 SPA «Дубли» на семантических токенах TN.
- `infra/` — docker-compose дев-стенда + `.env.dev.example`.

## Тесты

## Сознательные отходы от стека (ADR на будущее)

- **Без vector DB / embeddings** (ТЗ §9, Weaviate) — заменено хешами и сравнением
  карточек под объём MVP; «другой ракурс» приближается контекстом. Возврат — MVP-2/3.
- **UIKit/tn-bridge не вендорятся** (приватный GitLab) — UI на токенах с тем же
  неймингом для лёгкой замены на `TN*`-компоненты.
- **Авторизация выключена** — прод-путь OIDC/JWKS не реализован в этом заходе.
